# EmpleoJoven

Plataforma tecnológica orientada a facilitar el acceso de jóvenes y recién graduados al empleo formal.

## Objetivo

Conectar jóvenes con empresas mediante perfiles profesionales, validación de habilidades y búsqueda de ofertas laborales.

## Funcionalidades

- Gestión de perfiles
- Validación de habilidades
- Búsqueda de empleo
- Publicación de vacantes
